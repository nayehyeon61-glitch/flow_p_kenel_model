devk_band_sphNW 위, G(x) 입력이 어디에도 없음). 같은 옵션, 600번. 2017 의 같은 60 IC × 8 member, IC 짝 bootstrap
2000회(`scripts/pair_nophys.py devflow_lineW devflow_lineNW`, `flow_nophys.json`). 변수별 표는 `flow_nophys_vars.md`.

## 읽기

- 평균은 core·kernel 단계와 같다. G(x) 는 1일째만 확실히 돕고(−4.1 %), 3일부터는 측정되지 않는다.
- CRPS 는 1일(약 4 %)과 3일(0.6 %)에 물리 쪽이 유의하게 낫다. z500 CRPS 는 모든 선행에서 물리 쪽이 낮다(10일 328 대
  336, 2.4 %; 변수별 검정은 안 함).
- 로그 점수는 차이가 10일까지 남는다. IGN 이 1~10일 모두 유의하게 물리 쪽이 낫다. kernel 단계에서는 10일에 차이가
  사라졌는데(+0.001), FM 을 거친 뒤에는 10일에도 +0.015 로 남는다. 크기는 앙상블 entropy 차와 비슷하다: 물리 FM 이 같은
  보정(s/s 1.11~1.15, 양쪽 비슷)에서 더 좁은 분포를 낸다.
- entropy–오차 상관은 1~7일에 무물리가 더 높다. 무물리는 분포가 넓은 대신 그 넓이가 오차와 더 잘 맞는다(검정 안 함).
- 세 arm 중 IGN·z500 CRPS 는 G-flow 가 가장 좋고, 물리 FM, 무물리 FM 순이다.
- 다음: 같은 물리 kernel 위에서 G 를 전혀 읽지 않는 FM(`devflow_nogW --no-gcond`)으로, FM 안의 G(x̄) 몫과 kernel·core 의
  G(x) 몫을 나눈다.
