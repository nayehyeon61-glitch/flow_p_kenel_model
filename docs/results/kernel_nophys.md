# 물리장 G(x) 대조: kernel 단계 (2017, 2026-11-23)

물리 arm `devk_band_sphW`(core_gngmz8W 위) 대 무물리 arm `devk_band_sphNW`(core_ngmz8W, G(x) 입력 없음, 그 위 kernel 도
G(x) 를 읽지 않음). 같은 학습 해(2008–2015), 같은 선택 사항, 같은 반복 수(devk_m 800 → band 400). 2017 의 같은 60 IC,
kernel 의 antithetic 8 member. 선행 1 / 3 / 5 / 7 / 10일. 구간은 IC 에 대한 짝 bootstrap 2000회의 95 %
(`scripts/pair_nophys.py`, 결과 `kernel_nophys.json`). 변수별 표는 `kernel_nophys_vars.md`(500회).

주의: 무물리 kernel 의 e0 스펙트럼(`--e0-spec`)은 물리 kernel 의 파일(`diag_spectra_seq_m.json`)을 그대로 썼다. 처음
noise 의 띠별 크기만 들어가는 작은 누설이다.

## 읽기

- 평균(앙상블 평균의 오차)은 core 단계와 거의 같다. G(x) 는 1일째만 확실히 돕고(−3.5 %, core 단계 −3.48 %), 3일 이후는
  측정되지 않는다. 1일 손실은 바람·기온·msl 에 몰려 있고 z500 은 차이 없음(`kernel_nophys_vars.md`).
- 분포에서는 차이가 하나 더 보인다. IGN(로그 점수)은 물리 arm 이 7일까지 유의하게 낫다. 그 차는 거의 전부 예측 entropy
  H 의 차와 같은 크기다: 물리 kernel 이 더 좁은 분포를 내면서 보정(spread/skill ≈ 1)은 같다. 즉 7일까지는 G(x) 가
  있으면 같은 보정에서 더 날카로운 분포를 낸다. 10일에는 이 차가 사라진다(무물리는 H 가 여전히 0.016 크지만 IGN 은 같음).
- CRPS 는 1일만 유의(물리가 3.5 % 나음), 그 뒤는 구간이 0 을 포함. entropy–오차 상관은 3~7일에 무물리가 조금 높다
  (검정 안 함).
